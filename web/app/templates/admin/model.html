Cara kerja

Melatih model tetap dilakukan dari terminal, bukan dari halaman ini, supaya request web tidak tertahan selama proses latih. Setelah artefak jadi, unggah berkasnya di atas lalu tekan Aktifkan. Server langsung memuat model baru tanpa perlu dijalankan ulang. 

python ml/src/training/train_svm.py --csv data/landmarks.csv
python ml/src/evaluation/evaluate_svm.py --compare

Versi aktif juga dipulihkan otomatis saat server mulai, jadi pilihan Anda tidak hilang setelah restart. Model aktif tidak bisa dihapus sebelum ada versi lain yang diaktifkan.
